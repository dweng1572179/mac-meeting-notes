# Meeting Notes 0.4.2

One editable Notes document, and reliable saved-source answers.

- Notes replaces the separate Your notes and AI notes views. Existing summaries open directly, and any differing legacy typed notes remain in the same document. Your original saved fields remain intact.
- Edits autosave and are used consistently for search, questions, and export. Clearing Notes stays cleared. Deleting a transcript keeps the notes.
- Processing and queued metadata saves cannot replace newer note edits. Update notes from transcript uses the current document and keeps edits made while the request is running.
- Answers cite saved passage IDs; the app retrieves the exact text. This removes failures caused by model-copied quote formatting. An unavailable answer is shown plainly instead of becoming a citation error; invented source IDs remain rejected.

Regression checks, independent review, desktop/compact browser checks, and a live OpenAI check using only synthetic text cover the changes. Existing meetings do not need reprocessing.

Stop every recording before updating. This beta remains ad-hoc signed and unnotarized; macOS may request Keychain/audio permission again. Replace the existing app in Applications; do not choose Keep Both.
