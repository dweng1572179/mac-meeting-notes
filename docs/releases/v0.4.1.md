# Meeting Notes 0.4.1

A quieter question interface and a more readable transcript.

- Meeting and library questions share a compact composer with one focus border, an expanding input, a small send control, and consistent pending/error states. Long questions fit without a resize handle or horizontal overflow.
- Plain transcripts no longer repeat “Transcript section” for every audio chunk. Long passages gain display-only paragraph breaks; timestamps and source provenance remain available. Speaker-section scope stays visible for diarized recordings.
- Searches still match phrases spanning the added paragraph breaks. The original saved text, copy, and export are unchanged.
- AI notes and answers render Markdown emphasis and heading levels instead of exposing formatting markers. Model-supplied HTML remains escaped text.

Frontend regression checks, desktop/compact interaction checks, and independent code review cover these changes. This patch changes presentation; it does not reprocess saved meetings or add transcription charges.

Stop every recording before updating. This beta remains ad-hoc signed and unnotarized, so macOS may request Keychain/audio permission again. Download the DMG from this release and replace the existing app in Applications; do not choose Keep Both.
