# Meeting Notes 0.4.4

Live transcription recovers from temporary service failures and continues past isolated bad sections while preserving unfinished audio.

- Retries temporary network, timeout, rate-limit and server failures up to three times with backoff; saved sections are not uploaded again.
- Remembers rejected sections, keeps transcribing newly recorded sections, and requires explicit retry before an incomplete meeting can finish. Authentication and quota failures remain actionable errors.
- Keeps usable transcript text when optional speaker fields are malformed. Interrupted response bodies are classified as network/timeout failures.
- Shows canonical transcript words when speaker annotations disagree, including in search and enrichment.
- Keeps missing-capture-duration warnings visible after audio callbacks resume.
- Synchronizes a focused, unmodified notes editor after generation while preserving unsaved edits. Refresh and transcription status messages describe actual work.
- Produces more specific notes for classes and conversations, requires substantive decisions and explicit commitments, and excludes an unchanged generated baseline from fresh source evidence.

Validated with synthetic Spanish/English speech, a real API final-decision fixture, fault-injection tests and a mounted editor check. These checks do not establish physical Bluetooth reconnection, accurate cross-section speaker identities, or error-free recognition of real speakers. See the [reliability audit](../reliability-audit-2026-09-22.md).

Stop every recording before updating. This beta remains ad-hoc signed and unnotarized; macOS may request Keychain/audio permission again. Replace the existing app in Applications; do not choose Keep Both.
