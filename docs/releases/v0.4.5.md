# Meeting Notes 0.4.5

Recording now asks macOS to prevent idle system sleep until capture stops. The display can turn off. Keep the lid open and power connected; closing the lid, manually choosing Sleep, or a depleted battery can still interrupt capture.

- Uses the native IOKit power assertion, with no helper process or new dependency.
- Releases the assertion after Stop, setup failure, or recorder disposal. If macOS rejects protection, recording continues with a visible warning.
- Adds an explicitly run 110-minute native AAC rotation stress check covering both sources, frame totals, section decoding and clean stop.

The stress check uses accelerated synthetic audio. It does not establish 110 minutes of live hardware capture or classroom speech intelligibility. Microphone device selection remains fixed at recording start; select the intended input before starting.

Stop every recording before updating. This beta remains ad-hoc signed and unnotarized; macOS may request existing Keychain/audio permissions again. Replace the existing app in Applications; do not choose Keep Both.
