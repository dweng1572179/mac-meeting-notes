# Meeting Notes 0.3.0

A fuller meeting workflow: useful transcripts, configurable recognition, and clearer recovery.

- **Language and vocabulary:** save a spoken language, names/technical terms, and an optional higher-accuracy transcription model. The existing lower-cost model remains the default. Preferences guide recognition; they do not train your voice or guarantee accent accuracy.
- **Transcript workspace:** read/search/copy saved or partial transcripts, and export Markdown to Downloads. Exports include original notes, enhanced notes, meeting metadata, transcript, capture coverage, and incomplete-processing labels.
- **Ask this meeting:** questions use exactly the open completed meeting, with supporting source excerpts. Questions no longer silently discard text after the first 8,000 bytes. Source selections above 200,000 UTF-8 bytes are rejected with an explicit next step.
- **Search your library:** find content inside notes/transcripts and accented names without accent marks.
- **Recovery continuity:** specific key/settings actions, separate transcription/enrichment progress, retry-save, clearer silence outcomes, and a fresh-meeting action that preserves the old note. Explicit no-speech retries reprocess empty results with current settings and can incur another API charge; real saved transcript chunks remain untouched.

Original notes, session files, Keychain storage, and native chunked capture remain compatible. No new runtime dependencies.

## Install

Download `Meeting-Notes.dmg`. Stop every recording and quit Meeting Notes before replacing the app in Applications. Never install over an active recording or choose Keep Both.

This beta remains ad-hoc signed and unnotarized. macOS may require Open Anyway and renewed audio permissions. Connect/select Bluetooth devices before recording; seamless switching, speaker diarization, live captions, and signing/notarization are not included in this release.

Recognition controls are not a guarantee that every accent or recording will transcribe correctly. Review the saved transcript and capture warnings.
