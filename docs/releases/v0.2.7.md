# Meeting Notes v0.2.7

Long recordings now use native five-minute AAC chunks. Each successful transcript is checkpointed immediately; retry continues from saved progress. Dense speech that reaches the transcription output limit is retried in smaller chunks. Pending source audio stays local until its transcript is safely saved.

- Live warnings identify missing or stalled system/microphone capture, including empty callbacks and write failures.
- Saved meetings distinguish elapsed time from captured duration, retain partial/interrupted-capture warnings, and label overlapping source tracks honestly.
- Safe OpenAI errors distinguish invalid audio/key, model access, rate/quota limits, oversized input, timeout/network and server failures, with request IDs when available.
- Notes survive capture, API, storage and retry failures. Existing local JSON libraries remain compatible.
- No ffmpeg, new runtime dependency, meeting bot, or database.

Verification includes independently decoded chunks from over ten minutes of synthetic audio; simulated middle-chunk failure/reopen/retry without re-uploading saved chunks; storage failure; empty system audio; silent microphone; capture-health counters; source isolation; and error-contract checks. A live OpenAI run processed 340.4 seconds of generated speech into two chunks and 1,224 transcript words, preserved the final decision and original notes, reopened the completed session, and removed its audio.

**Updating:** stop all recordings and quit Meeting Notes before replacing the Applications copy. This beta is ad-hoc signed and not notarized; macOS can request audio permissions again after an update. Executable-change detection warns about that risk but does not eliminate TCC identity resets. Stable Developer ID signing/notarization remains on the roadmap.

Download `Meeting-Notes.dmg` for Apple silicon, macOS 14.2 or later. Preserve your existing Applications copy’s location; choose Replace, never Keep Both. Your local meeting library and Keychain key are separate from the app bundle.
