# Meeting Notes v0.5.0

- **Windows x64 beta:** native default-microphone and default-output capture, Windows Credential Manager storage, recoverable WAV sections, and a per-user installer with WebView2 setup. Existing Mac AAC recordings remain compatible.
- **Conversations that stay with your notes:** separate meeting, folder, and library chats retain full answers, citations, and drafts across navigation and restart. Requests continue when you navigate away. An interrupted request waits for an explicit retry; the app does not automatically repeat the paid call. Answers are readable and copyable, sources expand quietly, and storage/copy failures are visible.
- **Safe follow-ups:** up to four prior turns help resolve references while current saved passages remain the evidence. Only request context is shortened; displayed and saved answers remain complete. Starting a new conversation preserves the current draft. Deleting a meeting or transcript first clears related saved AI answers while preserving unrelated conversations and aggregate drafts; a cleanup failure blocks deletion.
- **One editable notes document, with recovery:** updating notes from a transcript preserves the immediately previous document. **Restore previous notes** swaps the two versions, so restoration can be reversed. Concurrent edits take priority over generated replacements. Existing categories are available as suggestions when organizing notes.
- **Transcription recovers while capture continues:** transient failures receive fast retries followed by capped periodic retries during recording. Stop starts a fresh, finite final-processing attempt. Saved transcript sections are reused; retained audio remains available when transcription or checkpointing fails. Invalid credentials and other permanent errors still need attention.

Planned artifacts: **Meeting-Notes.dmg** for Apple silicon Mac, **Meeting-Notes-Setup.exe** for Windows x64, and **SHA256SUMS.txt**. Availability and final artifact verification are pending the release checks below.

Stop recording and quit before updating. The Mac app is ad-hoc signed and unnotarized; the Windows installer is unsigned. See the [README](../../README.md) for permissions and first-launch instructions.

## Known limits

Windows uses the microphone and default output selected at recording start. Stop and start again after changing devices; automatic rebinding and native Windows ARM builds are not included. Physical Windows microphone/loopback, Bluetooth, device removal/switching, sleep/wake, and real Edge playback remain unverified. Installing WebView2 on a clean Windows PC without an existing runtime also remains unverified; a hosted-runner installer smoke test does not establish either hardware behavior or that bootstrap path.

Questions currently use completed meetings and at most the latest 20 in a library/folder scope, with an explicit source-size limit. Deleting a meeting may also clear answers in a related folder or library conversation, even if that meeting was not cited. Model output and section-local speaker labels still require review. Restore retains one previous document, not unlimited history. Local storage failure preserves the current conversation in memory but requires attention before closing; interrupted or failed API requests may incur another charge when retried.
