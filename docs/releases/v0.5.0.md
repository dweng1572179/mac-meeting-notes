# Meeting Notes v0.5.0

- Windows x64 support: native microphone and default-output recording, protected API-key storage, durable WAV recovery, and a per-user installer with WebView2 setup.
- A quieter question interface with formatted answers, expandable sources, follow-up context, and retry continuity. Previous answers help resolve follow-ups; current saved notes and transcript remain the evidence.
- The AI response schema restricts source references to the actual supplied passages. Existing notes, recordings, and Mac AAC processing remain compatible.

Downloads: **Meeting-Notes.dmg** for Apple silicon Mac; **Meeting-Notes-Setup.exe** for Windows x64. Verify downloads against **SHA256SUMS.txt**.

Stop recording and quit before updating. The Mac app is ad-hoc signed and unnotarized; the Windows installer is unsigned. See the README for first-launch instructions and platform permissions.

Windows records the default microphone and output selected at recording start. Restart recording after changing devices. Physical Windows microphone/Bluetooth/Edge capture has not been validated on a user machine; hosted CI and synthetic checks cannot establish that hardware coverage. Windows ARM is not a native build target for this release.

Validation receipt will be added after the final release checks finish.
