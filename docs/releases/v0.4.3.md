# Meeting Notes 0.4.3

Speaker timestamp errors no longer stop a usable transcript.

- Keeps returned transcript text when speaker timestamps or labels are invalid, and continues processing the remaining audio.
- Shows a notice when speaker labels are unavailable. Invalid labels and timestamps are never saved as verified speaker turns.
- Applies the same handling to recording-time sections and older whole-file recordings. Saved chunks remain reusable on retry, and audio is deleted only after its transcript is durably saved.
- Does not add a paid transcription request for this fallback. Actual API failures and output-limit checks still preserve unfinished audio for retry.

Stop every recording before updating. This beta remains ad-hoc signed and unnotarized; macOS may request Keychain/audio permission again. Replace the existing app in Applications; do not choose Keep Both.
