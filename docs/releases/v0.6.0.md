# Meeting Notes v0.6.0

Local onboarding, clearer settings, and easier access to your notes and chat.

- Optional first-run setup: start typing without an account or API key, or connect your own OpenAI key for recording and AI. Existing libraries open normally.
- Separate AI, Recording, Privacy & data, and Connections settings. Explain remote processing and separate API billing before key entry; open the relevant native permission pages and local data folder.
- Remove a saved API key without deleting notes. Removal is blocked during recording/processing; overlapping key changes are rejected. Removing the local key does not revoke it at OpenAI or cancel requests already sent.
- A credential-store error no longer prevents the local library from opening. Key input validation and a local-content security policy strengthen the native boundary.
- Compact expandable meeting details, a chat column on wide windows, and a docked chat panel at smaller widths. Conversation history scrolls separately from the composer.

The app remains accountless and stores notes locally, but AI processing uses OpenAI. Notes/chats are not encrypted by the app. Google/Microsoft connections, mailbox import, cloud sync, same-note recording resume, trash, rich-text editing, named chat archives and streaming are not added by this release.

## Validation and limits

Local checks: 14 native-API wrapper tests, 73 frontend tests, 7 focused Rust settings tests, Svelte check with zero errors/warnings, Clippy, production frontend build, and isolated native macOS startup/settings/save/permission-link checks. Browser checks covered first-use skip, key save/removal simulation, unsaved settings dialogs, long chat and 900×620/1440×850 layouts. No real recording or paid AI request was used for these changes.

Release publication requires both macOS and Windows CI to pass before installers are uploaded. The Windows installer remains a beta: physical microphone/loopback, Bluetooth/device switching, sleep/wake and clean-machine WebView2 installation still need real hardware verification. macOS remains ad-hoc signed and unnotarized; Windows has no Authenticode signing certificate.

Stop recording, wait for processing, and quit Meeting Notes before updating. Keep the supplied SHA256SUMS.txt to verify downloaded installers.
