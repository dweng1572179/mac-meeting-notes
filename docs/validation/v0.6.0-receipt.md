- Independent review found three issues (recording return access from setup, chat scroll while typing, missing remote-processing disclosure on returning-user key setup); all were fixed. Native inspection additionally caught unsupported `window.confirm`, replaced with the app's established HTML dialog pattern and reverified natively.
