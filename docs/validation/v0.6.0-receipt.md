# v0.6.0 validation receipt

## Local source and UI verification

- 14 native API wrapper tests and 73 Vitest tests passed on the final frontend source.
- Seven focused Rust settings tests passed, including unavailable credentials, idempotent removal/failure preservation, active processing guards, overlapping credential operations, key bounds, and fixed native destinations. Tests used mock credentials, not the saved production account.
- Svelte check: zero errors and zero warnings. Production frontend build and Rust Clippy (`--locked --lib -- -D warnings`) passed.
- Browser inspection used synthetic data at 1180×760, 1440×850 and 900×620. Setup could be skipped to type notes without a key. Simulated save/remove reflected the right key state. Settings navigation retained drafts; the final native HTML discard dialog supported keeping/discarding changes.
- Long synthetic chat scrolled independently; at 900×620 the composer ended at y=522 and there was no horizontal overflow. Typing a follow-up left the inspected history scroll position at 120 instead of jumping to the bottom.
- Isolated native bundle `com.dweng.meetingnotes.qa20260923setup` opened bundled assets at `tauri://localhost` under the production content security policy. Bootstrap, local synthetic note creation/save/navigation, preference saving and restart persistence passed. No recording or paid AI request was started.
- Native fixed links opened macOS Microphone and Screen & System Audio Recording settings without changing permissions. Open data folder selected the disposable app-data directory in Finder. The production API key was neither displayed, changed nor removed.
- Independent review found three issues (recording return access from setup, chat scroll while typing, missing remote-processing disclosure on returning-user key setup); all were fixed. Native inspection additionally caught unsupported `window.confirm`, replaced with the app's established HTML dialog pattern and reverified natively.

## Storage and cleanup

Disposable native app/data, browser session and HTTP preview server were stopped/removed after verification. Rebuildable Rust target output and duplicate v0.5.0 release staging were removed, reclaiming 6,444,769,280 allocated bytes (6.00 GiB). The existing v0.4.5 rollback bundle and preinstall data backup were preserved; the earlier Downloads rollback ZIP was already absent. User session files and recovery audio were excluded from cleanup. Two small synthetic screenshots are kept as durable UI evidence.

Native UI verification did not exercise physical audio capture, Microsoft/Google accounts, or cloud-managed billing.
